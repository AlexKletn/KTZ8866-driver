# KTZ8866-driver

[English version](README.md)

[Как участвовать](CONTRIBUTING.ru.md) · [GPL-2.0-only](LICENSE)

Рабочее пространство драйвера Linux для контроллера подсветки и питания LCD Kinetic KTZ8866. В нём есть переиспользуемая библиотека и отдельный модуль ядра.

Библиотека `no_std` настраивает LED-каналы, яркость и смещение матрицы через переданную шину регистров. Значения регистров и задержки задаёт профиль платы.

Адаптер из `kernel/` записывает регистры через привязанный клиент I²C ядра Linux и обеспечивает задержки со сном. Он предназначен для включения в модуль ядра, который использует библиотеку.

## Отдельный модуль ядра

Соберите `ktz8866_rust.ko` на базе настроенного и собранного ядра с поддержкой Rust, I²C и подсветки.

```sh
make -C "$KERNEL_BUILD" M="$PWD/crates/ktz8866-module" modules
```

Модуль привязывается по `kinetic,ktz8866` и регистрирует устройство подсветки Linux для одной микросхемы. Выберите его драйвером соответствующего клиента I²C. Питание он получает через регуляторы платы `vddpos` и `vddneg`. Согласованная работа двух микросхем остаётся задачей драйвера панели.
